# pinright technical report

The final report (version 1.0.0, 2026-11-03) is [kit/pinright-report.md](kit/pinright-report.md),
rendered as [kit/pinright-report.pdf](kit/pinright-report.pdf):

```bash
node paper/build-pdf.mjs --css paper/kit/pdf.css paper/kit/pinright-report.md
```

The draft that stood here (pinright 0.2.0, Sonnet only, run v5) is in the git history. The kit next to
the report holds the data behind every table and figure ([kit/data/](kit/data/)), the figures
([kit/figures/](kit/figures/)), the source of every claim ([kit/claims.md](kit/claims.md)) and the
launch copy ([kit/copy/](kit/copy/)).
