Method

  • Claude Code 2.1.308 in headless mode, driving Sonnet 5.5, Haiku 5.5 and Opus 5.5.
  • 12 coding tasks we wrote (8 npm, 4 PyPI) that ask for pinned versions. 2 runs per arm and model.
  • Arms: no docs; docs-only (pinright with its verdict off); pinright MCP server; hook only; MCP plus hook. A no-pin reference installs the same packages without a version.
  • Each project audited with npm audit or pip-audit, which share no code with pinright, then installed and built.
  • 360 agent runs plus 112 docs runs, USD 31.34 in total at API list price.

About 30 alerts per project without docs, 0.3 with pinright

Without tools, projects averaged 29.8 to 31.9 whole-tree alerts. With the pinright MCP server every model averaged 0.3, the same as installing the packages with no version. That 0.3 is nuxt's: its current release pulls deepmerge, glob and minimatch versions with advisories and no fix yet.

40% to 42% of direct pins had a known advisory, 0% with pinright

Sonnet pinned 66 of 164 direct dependencies with an advisory, Haiku 63 of 157, Opus 66 of 159. Examples: axios@1.7.9, pillow@11.0.0, pyjwt@2.10.1. No arm pinned a package or version that does not exist.

Current docs do most of the work. The verdict does the rest.

The docs-only arm is pinright's own server with the verdict turned off, documenting each package's latest release. Steering the agent to current versions that way cut alerts by 89% to 99%. Without the verdict, Sonnet pinned a vulnerable next@15.5.0 in both of its next-auth runs and Haiku a next-auth beta with advisories in both of its own, and the runs took more turns and cost 1.5x to 1.8x more than with the full server.

The hook-only remainder comes from next 15.5.28, which has no advisories itself but pulls a postcss with some. On the same 394 lockfiles, pinright's check-manifest flagged the same packages as npm audit and pip-audit (mean Jaccard 0.96 for npm, 1.00 for PyPI).

16 of 16 runs wrote the current API, against 9 to 14 without docs

Eight tasks that only come out right with a library's current major: Next.js 16, Tailwind CSS 4, Zod 4, AI SDK 7, Express 5, ESLint 10, Pydantic 2 and LangChain 1. A run counts when it installs, builds, passes a smoke test, pins the asked major and uses no removed or deprecated API. Without docs, every model wrote AI SDK 5/6 code for AI SDK 7, and most LangChain runs pinned an early 1.x whose imports fail. The models already knew five of the eight APIs, so the gap rests on the other three. The no-docs intervals for Sonnet and Opus overlap 16 of 16; Haiku's does not.

Without an agent, pinright's docs answered 25 of 28 and 33 of 45 questions in two held-out sets nobody tuned on, over libraries outside the benchmark. A probe checks for strings of the current API, not for a correct answer.

The hook blocked or asked on 1.46% of 25,077 public commands

We ran 25,077 commands and manifest writes from 180 public repositories (CI steps, package.json scripts, README lines, Dockerfiles, Makefiles) through the real hook. The 1.0.0 release blocked or asked about 1.46%, and denied 0.13%. Most of those ask on purpose: a version in a variable, a git source, another package index. 32 were true positives, such as npm install -g pnpm@8 with 26 advisories in a public workflow. The 13 root causes we fixed were found on this same corpus, so there is no held-out set. We also replayed a month of our own Claude Code sessions, 154,402 distinct tool calls: after two fixes it prompted, the hook misread 10 of them, against 52 true positives and 79 asks by design.

Latency

The hook runs before every shell command. A command that installs nothing took 121 ms at the median; one install took 358 ms with a warm cache and 2.4 s cold. With the MCP server, runs took about 2 to 4 more agent turns and 1.5 to 2 times the API-equivalent cost of a run without tools.

Caveats

  • One vendor's models, all driven by Claude Code. Other agents may pin differently.
  • Tasks we wrote, and new projects only. Editing an old codebase is a different problem.
  • Advisory data from the two days of the run, 2026-11-02 and 2026-11-03. New advisories change the counts.
  • 2 runs per arm and model, so 16 to 24 runs per cell. Read the intervals, not just the bars.
  • pinright knows published advisories only. A package with no advisory on record has none reported yet.
  • The public false-positive corpus is CI and README commands. The agent-session replay covers one user's month of work.
